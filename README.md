🎯 Objetivo de la PFO1

El objetivo de esta PFO1 es desarrollar una landing de portafolio personal que permita presentar mi perfil, habilidades y una forma de contacto.

La página incluye:

- Nombre y apellido.
- Presentación personal.
- Habilidades y tecnologías.
- Proyectos y trabajos realizados durante mi formación.
- Sección personal.
- Formulario de contacto.
- Enlace visible y funcional al perfil de GitHub.
- Diseño responsive.
- Navegación entre las diferentes secciones.

---

🛠️ Tecnologías utilizadas

HTML5

Se utilizó HTML5 para construir la estructura y el contenido de la landing.

Se aplicaron elementos semánticos como:

- "header"
- "nav"
- "main"
- "section"
- "article"
- "aside"
- "form"
- "footer"

También se utilizaron etiquetas de formulario correctamente asociadas mediante "label" e "id".

CSS3

El diseño fue desarrollado con CSS propio.

Se utilizaron:

- Variables CSS.
- Flexbox.
- CSS Grid.
- Media queries.
- Transiciones.
- Animaciones.
- Unidades relativas.
- Diseño responsive.

Google Fonts

Se utilizaron las fuentes:

- Inter
- Space Mono

La elección busca combinar una tipografía clara para el contenido general con una estética relacionada con el ámbito tecnológico para los detalles técnicos.

---

🎨 Decisiones de diseño

Elegí una estética oscura y minimalista relacionada con el ámbito del desarrollo de software.

Paleta

La página utiliza principalmente:

- Fondos oscuros.
- Blanco y gris para el contenido.
- Violeta como color de acento.

El violeta se utiliza para destacar elementos importantes como títulos, números de sección, enlaces y detalles visuales.

Estructura

La landing está organizada en las siguientes secciones:

1. Inicio
2. Sobre mí
3. Habilidades
4. Proyectos
5. Sección personal
6. Contacto
7. Footer

La navegación superior permite acceder rápidamente a las diferentes partes de la página.

Responsive

El diseño se adapta a diferentes tamaños de pantalla mediante media queries.

En dispositivos pequeños:

- Las columnas pasan a una sola columna.
- Los botones se adaptan al ancho disponible.
- Las tarjetas se reorganizan.
- La navegación se simplifica.

---

✨ Interactividad y animaciones

Se incorporaron diferentes efectos mediante CSS.

Entre ellos:

- Transiciones en botones.
- Efectos hover en tarjetas.
- Cambios visuales en badges.
- Animación flotante en la tarjeta principal.
- Animación del cursor dentro del bloque de código.

Estos efectos fueron utilizados para aportar dinamismo sin dificultar la lectura.

---

♿ Accesibilidad

Se incorporaron algunas decisiones orientadas a mejorar la accesibilidad:

- Uso de HTML semántico.
- Atributo "lang="es"".
- "aria-label" en elementos de navegación cuando resulta necesario.
- Asociación entre "label" e inputs mediante "for" e "id".
- Uso de textos descriptivos.
- Estados ":focus" para los campos del formulario.
- Contraste entre el contenido y el fondo.
